# FORMDAY v0.8.26 — 운동 종료와 계획 수행량 분리

- 사용자 최종 지시: 상단 완료 버튼으로 운동을 끝내면 현재 수행한 중량·횟수 그대로 운동 완료로 확정한다. 남은 계획 세트를 완료로 바꾸지 않는다. 명시적으로 부분 완료를 선택한 경우에만 PARTIAL. 완료한 세트가 하나 이상 있어야 확정 가능.
- 명시적 완료는 COMPLETED로 저장하며 순환형 프로그램의 다음 루틴으로 이동한다. 이전 부분완료 자동전환 시안은 적용하지 않는다.
- 캘린더의 연결된 완료 일정은 운동 종료 상태를 표시한다. 실제 N/M 세트 및 미수행 세트를 별도 표시하고 미수행 세트를 실제 수행량으로 집계하지 않는다.
- 기존 v0.8.25의 COMPLETED 세션과 completed=false 캘린더 링크도 세션 상태 및 저장된 세트로 화면에서 읽기 복구한다. 원본 일괄 변환은 하지 않는다.
- 부분 완료는 별도 표시 및 집계. 연결된 운동 전체 완료 토글 차단, 직접 등록한 웨이트의 일괄 완료 확인. 기존 저장 경로, 운동량 집계, 중복 방지 및 보안 규칙 유지.
- 진행 중 삭제/교체한 세트의 기준은 수정된 구성이다. 실제 로그인 계정의 당일 기록은 직접 조회·변경하지 않았다.
