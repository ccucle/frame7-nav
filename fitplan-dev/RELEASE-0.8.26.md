# FORMDAY v0.8.26 — 부분 완료와 전체 완료 분리

- 운동 종료 시 실제 완료 체크가 없는 세트가 있으면 자동 부분 완료로 저장. 명시적 부분 완료도 보존. 순환 프로그램 진행 위치는 전체 완료일 때만 이동.
- 이전 버전의 COMPLETED 상태라도 일부 세트만 완료했다면 읽기 화면에서는 부분 완료로 표시. 기존 원본·프로그램 진행 위치를 일괄 수정하지 않음.
- 캘린더 반영은 실제 세트와 확정 상태를 함께 확인. 링크 ID만으로 전체 완료하지 않음. 월·주·일·날짜 상세에 부분 완료 표시. 일별 통계에서 전체 완료와 부분 완료 횟수를 분리. 실제 수행 세트 및 운동량은 유지.
- 연결된 운동의 전체 완료 토글 차단. 개별 세트 기록 수정은 기존 경로 유지하며, 연결된 부분 완료를 전체 완료로 승격하지 않음. 저장 실패 및 다른 기기 변경 검증 유지.
- 진행 중 명시적으로 삭제/교체한 세트는 수정된 운동 구성을 기준으로 판단. 개인 기록에 직접 접근하거나 소급 변경하지 않음.
