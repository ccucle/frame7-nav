# FORMDAY v0.8.28 — 식사 구분
- 일반 식단과 AI 식단 가져오기: 날짜와 mealPeriod (breakfast/lunch/dinner/snack 또는 아침/점심/저녁/간식) 선택. 새 식단에 시각 입력 불필요.
- 주간/일간: 네 식사 구분 행을 시간표와 분리. 월간/날짜 상세는 시각 대신 구분 표시. 운동과 체중의 시각은 유지.
- 기존 날짜, 기록, 영양 데이터와 실제 시각 보존. 구분 미기록 식단은 저장된 시각 기준 읽기 전용 추정 (05~11시 전 아침, 11~15시 전 점심, 17~22시 전 저녁, 나머지 간식). 편집·저장할 때만 명시 분류를 기록. 기존 식단을 자동 마이그레이션하지 않음.
- schema v3 유지: detail.mealPeriod + mealTimeBasis; 새 구분형 기록에 start/end 호환용 고정 앵커를 기록하되 실제 섭취 시각이 아님. 구버전 앱 또는 기존 Connect에서 분류 메타데이터가 소실될 수 있으므로 새 버전으로 업데이트하고 기존 Connect 변경은 별도 검증 필요.
- 기존 AI JSON start/end도 받아 기존 시각을 보존하고 분류를 제안. 같은 날짜·같은 아침/점심/저녁에 AI 중복 가져오기 차단; 간식은 다른 음식 허용, 같은 음식/분량은 차단. 수동 기록은 기존처럼 사용 가능.
- 기존 로컬 기록 저장·동기화·백업 흐름 유지, 별도 서버/보안 규칙/요금 변경 없음. 실제 계정 및 모바일 화면 검증 별도. 개인 데이터 없음. 원본 사진 메인 통합 PR은 계속 보류.
