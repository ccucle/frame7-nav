## 이번 구현 내용

1. **다크 스포츠 스타일 전체 적용**: 왼쪽 브랜드 및 내비게이션, 상단 툴바, 기존 캘린더와 우측 기록 패널은 기존 기능을 유지하며 다크 테마로 변경. 식단·웨이트 상세 입력 모달은 현재 안정된 밝은 입력 스타일을 우선 보존.
2. **운동 대시보드**: 실제 기록 기반 운동 일정, 완료 훈련 날짜, 완료 본세트, 총 볼륨, 실제 체중, 부위별 볼륨, 1~10회 세트의 추정 1RM. 샘플 기록은 분석에서 제외.
3. **운동 도감**: 현재 FormdayWorkouts.catalog 전체 종목을 재사용하는 검색·부위·장비 필터. 일반적인 체크포인트 및 운동 등록 버튼. 이미지들은 Unsplash 공개 사진에서 불러오는 **분위기용 대표 이미지**로, 개별 운동의 정확한 수행 자세 영상은 아님.
4. **운동 실행**: 기존 저장된 오늘 웨이트 일정 선택, 종목별 세트 중량/횟수/RPE/완료 저장, 최근 같은 운동 기록 표시, 60/90/120/180초 휴식 타이머. 모든 저장은 원래 app.js commit 및 Core.upsert의 데이터 검증과 리비전 충돌 보호를 통과.
5. **성과 분석**: 주간 완료 세트의 kg×횟수 볼륨, 운동 일수, 주요 종목 추정 1RM. 추정치는 의료적/운동 안전 보장이나 정확한 최대 중량이 아님.
6. **기존 자료**: Core v3 저장 키, 내 식품, 즐겨찾기, 식단 스냅샷, 날짜별 반복 기록, 체중, 백업·복원, Google Auth 모듈 변동 없음.

## 필수 제한과 검증 구분

- Firebase 로그인 기능은 **동기화가 아님**. 이번 v0.4 역시 브라우저에 기존 기록을 저장하며 Firestore 보안 규칙은 deny-all로 유지.
- 새로운 결제, 클라우드 데이터베이스, 외부 유료 API, 자동 비용 발생 없음.
- 외부 운동 사진은 연결이 끊어지면 표시되지 않을 수 있으며, 실제 운동 지도용 이미지는 아님. 출처: https://unsplash.com/license . 제작된 UI 그래픽 및 문구는 FORMDAY 오리지널.
- 현재 동작 모드는 수동 세트 입력·완료 기록으로, 자동 추천 중량 계산/휴대폰 진동 알림/개인 루틴 템플릿 저장은 후속 개발.
- 카탈로그에 등록되지 않은 자유 입력 종목은 분석에서 기타로 분류.
- 동일한 브라우저에서 로그인 계정을 바꾸더라도 데이터는 로컬에 남음: 공유 기기 사용 경고 유지.
