# FORMDAY v0.8.0 — 운동 진행 화면

## 변경 이유

기존 세트 표는 작은 화면에서 가로로 밀리고 중량·횟수·완료·저장이 분리되어 있었다. 사용자가 제공한 운동 기록 화면을 바탕으로, 기존 FORMDAY 테마와 데이터 형식을 유지하면서 한 화면에서 운동을 기록하도록 구성했다.

## 사용자에게 보이는 변경

- 운동을 시작하거나 이어가면 운동 전용 화면으로 열린다. 고정 상단에 경과 시간, 일시정지/재개, 완료, 실제 본세트 운동량·완료 본세트·완료 종목을 표시한다.
- 종목별 기존 라이선스 이미지, 최근 확정 기록, 휴식 시간, 메모를 표시한다. 모든 종목과 한 종목씩 보기를 전환할 수 있다.
- 큰 중량·횟수 입력과 원형 완료 버튼으로 기록한다. 세트 번호를 눌러 워밍업을 전환하며 휴식 시간과 RPE는 상세 항목에서 입력한다.
- 세트 추가·마지막 미완료 세트 삭제, 종목 전체 완료/해제, 이전 기록 불러오기, 종목 교체, 검색창을 통한 종목 추가를 지원한다.
- 완료 체크 시 휴식 타이머가 시작되고, 운동을 멈추면 함께 멈춘다. 15초 추가·수동 시작/멈춤·닫기를 지원한다.
- 운동 화면 접기는 운동을 계속 유지하며 홈으로 돌아간다. 운동 관리에서 임시 보관, 부분 완료, 취소를 할 수 있다.
- 운동/종목 메모는 확정 기록에서도 읽을 수 있다.

## 데이터와 저장

- 기존 `formday_iron_independent_v1` 키와 v1 형식을 유지한다. Firebase 로그인·규칙·동기화 경로는 변경하지 않는다.
- 화면에 보이는 입력을 한 번에 검증하여 저장하며, 입력 변경 시 필드를 다시 그리지 않는다. 저장 실패·잘못된 값·다른 탭의 충돌에서는 입력을 유지하고 이동을 막는다.
- 최신 기록 다시 불러오기는 확인 후 이전 화면 입력을 버리며, 그 값을 새 데이터 위에 재저장하지 않는다.
- 이전 기록 불러오기는 과거 확정 기록의 완료 세트만 새 ID와 미완료 상태로 복사한다. 완료한 세트가 있는 종목의 교체·불러오기와 완료된 마지막 세트 삭제를 차단한다.
- 워밍업은 상단 본세트 수와 중량×횟수 운동량에서 제외한다. 근거 없는 소모 칼로리를 생성하지 않는다.
- 휴대전화 화면 숨김 시 정상 입력을 저장하고 운동/휴식을 멈춘다. 입력이 잘못되어 저장하지 못한 경우에는 화면 입력을 보존하고 시간 경계를 기억하여, 수정 후 저장할 때 숨겨진 시간을 제외한다.
- 새 세션, 완료, 취소 시 휴식 타이머를 초기화한다. 확정된 과거 기록과 원래 루틴은 진행 중 편집의 영향을 받지 않는다.
