# FORMDAY v0.8.22 — 훈련 프로그램 카드 정리 및 삭제

- 모바일 카드 이름과 유형 표시를 분리하고 긴 이름의 안전한 줄바꿈, 다음 운동 행, 두 열의 동일 높이 버튼을 적용한다.
- 버튼 문구를 운동 시작·캘린더 등록·수정·삭제로 줄인다. 요일 고정형은 요일별 요약을 표시한다.
- 프로그램 삭제는 선택한 프로그램에만 적용되며 확인창을 거친다. 기존 루틴, 실제 운동 세션 및 캘린더 일정을 유지한다.
- 기존 저장 및 동기화 흐름과 백업을 사용한다. 삭제 실패 시 원본과 카드가 유지된다.
- 실제 개인 프로그램을 이 업데이트에서 직접 삭제하지 않는다.
