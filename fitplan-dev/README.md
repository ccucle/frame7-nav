# FORMDAY v0.2 — 웨이트 기록과 캘린더 저장 확장

이 폴더는 개발 문서와 회귀 테스트용입니다. Render는 `fitplan/`만 게시합니다.
배포 대상은 기존 `fitplan-site-20261123` 브랜치의 FORMDAY 정적 사이트입니다.

## 변경 내용

- 웨이트 한 일정에 여러 종목과 종목별 세트를 기록합니다.
- 세트마다 중량, 횟수, RPE(선택), 워밍업 여부와 완료 여부를 저장합니다.
- 종목별 최근 실제 수행 기록을 보여주고 세트 추가·복제·삭제를 지원합니다.
- 완료한 본 세트의 중량 × 횟수만 운동량에 합산합니다. 워밍업은 완료 세트 수에는 포함하지만 운동량 합계에는 포함하지 않습니다.
- 60·90·120초 휴식 타이머에 일시정지·재개·초기화를 제공합니다.
- 반복 일정의 기본 계획과 날짜별 기록을 분리합니다. 날짜별 수정은 해당 날짜에만 반영하고, 기본 계획을 바꾸어도 저장된 실제 기록은 유지합니다.
- 반복 종료일, 특정 날짜만 삭제, 한 단계 되돌리기, 일정·운동 검색, 겹치는 시간대 일정의 나란히 표시를 추가했습니다.
- 체중은 측정 완료된 실제 기록만 그래프와 최근 측정에 반영합니다. 반복 체중 일정은 이전 측정값을 다음 날로 복사하지 않습니다.
- 유산소 운동 강도를 저장합니다. 식단의 칼로리·탄수화물·단백질·총 지방·그중 불포화지방 계산은 유지합니다.

## 저장과 이전 버전 호환

`formday_calendar_proto_v1` 저장 키를 그대로 사용합니다. 기존 단일 종목 기록을 종목·세트 구조로 변환하고, 반복 완료일 목록을 날짜별 기록으로 변환합니다.

변환 전에 없던 실제 기록을 추정해 만들지 않습니다. 기존 반복 데이터에는 날짜마다 다른 중량/측정값이 보관되지 않았기 때문에, 변환은 기존에 저장된 값과 완료일로만 이루어집니다. 기존 파일 자체가 잘못된 경우 원본을 보존하고 복원을 안내합니다.

저장은 유효성 검사 → 현재 버전 확인 → 직전 원본 보관 → 쓰기 순서입니다. 저장 실패 때 성공 알림을 띄우거나 편집창을 닫지 않습니다. 다른 탭이 먼저 저장하면 오래된 입력으로 덮어쓰는 대신 최신 기록 불러오기를 안내합니다. `localStorage`는 서버 트랜잭션이 아니므로 완전한 동시성 보장을 제공하지 않습니다.

백업은 `app: formday`, `version: 2`를 사용하는 JSON입니다. v1 백업도 유효성 검사 후 가져올 수 있습니다. 지원하지 않는 버전, 잘못된 날짜/시간/수치, 중복 ID, 손상된 파일은 거부하고 기존 기록을 유지합니다. 가져오기는 현재 데이터를 대체하는 작업이므로 화면에 명시적인 확인이 있습니다.

## 범위와 제한

- 계정, 서버 데이터베이스, 기기 간 동기화, Google Calendar 연동, 실제 AI API는 아직 없습니다.
- 기록은 사용하는 브라우저에 저장됩니다. 브라우저 데이터 삭제로 사라질 수 있으므로 내보내기를 통해 백업할 수 있습니다.
- 식품 영양성분은 기존 샘플 목록입니다. 검증된 전체 식품 DB, 바코드 및 제품별 영양성분 입력은 다음 단계입니다. 알 수 없는 식품의 값은 합계에서 제외하고 누락 사실을 표시합니다.
- 일정 5,000개, 날짜별 반복 기록 20,000개, 한 일정의 운동 30종목, 종목별 50세트를 지원합니다. 초과 데이터는 조용히 잘라내지 않고 명시적으로 거부합니다.
- 월 보기에서 단일 일정을 다른 날짜로 드래그할 수 있습니다. 반복 일정은 편집창에서 범위를 선택합니다. 주·일 보기의 드래그 및 리사이즈는 아직 없습니다.
- 자정이 넘는 일정은 두 날짜로 나누어 등록합니다.
- 기존 화면의 배치와 색상은 유지하면서 긴 운동 편집창, 모바일 입력 크기, 키보드 포커스 이동을 개선했습니다.

## 검증 실행

별도 패키지 설치 없이 Node.js의 내장 테스트 기능을 사용합니다.

```sh
node --check fitplan/app.js
node --check fitplan/core.js
node --check fitplan/workouts.js
node --test fitplan-dev/*.test.cjs
```

검증 범위는 구버전 변환, 반복 날짜 독립성, 완료 운동량, 실제 체중 집계, 저장 실패·충돌·복원, 미저장 입력 보존, 기본 계획 편집, 타이머 보정입니다. DOM 어댑터 기반 테스트는 실제 브라우저·모바일 렌더링을 대신하지 않습니다.

2. 로그인·사용자별 DB·백업 복원을 구현해 다른 기기에서도 같은 기록을 사용합니다.
