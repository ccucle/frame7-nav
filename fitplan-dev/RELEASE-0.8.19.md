# FORMDAY v0.8.19 — 프로그램 유형별 입력 분리

- 순환형에서만 포함할 루틴·순서 선택 표시.
- 요일 고정형은 7개 요일별 선택란만 표시하고 전체 저장 루틴을 직접 선택.
- 저장 시 요일별 루틴 ID를 중복 없이 도출하므로 별도 포함 체크 불필요. 동일 루틴 복수 요일 배정 지원.
- 각 모드의 미저장 입력을 모드 전환 시 유지하고 저장할 때 선택한 모드만 반영.
- 기존 프로그램 ID 및 저장 구조, 기존 운동 기록 유지.
- 고정형의 모든 요일이 운동 없음이면 저장하지 않고 안내.
- UI 회귀 검사 3개 추가.
