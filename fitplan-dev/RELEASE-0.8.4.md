# FORMDAY v0.8.4 — 운동 메모 입력란 제거와 자간 조정

운동 진행창에서 오늘의 컨디션·운동 메모와 종목별 메모 입력란을 제거한다. 종목 정보 아래에서 바로 세트 입력으로 이어진다.

## 변경 내용

- 메모 입력 요소와 전용 CSS를 제거한다.
- 세트 저장 시 메모 필드를 수정하지 않는다. 기존 운동·종목 메모는 저장된 기록과 완료 기록 보기에서 보존한다.
- 운동 진행창 기본 자간은 -0.2px, 제목은 -1px, 종목명은 -0.6px, 중량·횟수는 -0.3px로 소폭 조정한다. 날짜·종목 순서 영문 라벨의 과한 벌어짐도 줄인다.
- v0.8.3의 글씨 크기와 세트 행 높이, 주요 버튼 조작 영역을 유지한다.
- 화면 CSS·JavaScript 캐시와 표시 버전을 v0.8.4로 갱신한다.

## 확인

- 화면 동작 테스트 31개 통과, 실패 0개.
- 기존 메모가 있는 격리 데이터로 입력란 제거 후 개별 세트 완료·종목 전체 완료·일시정지·재개를 확인한다. 각 단계에서 메모가 테스트 저장소에도 보존되는지 검증한다.
- 다른 세트의 중량·횟수 및 미완료 상태를 보존하는 기존 검증도 유지한다.
- JavaScript 문법 검사와 `git diff --check` 통과.
- 실제 iPhone 기기의 터치·키보드 검증은 포함하지 않는다.

기존 Render 정적 사이트를 갱신한다. Firebase 설정과 기록 형식은 변경하지 않는다.
