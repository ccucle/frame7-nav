# FORMDAY v0.8.9 — 큰 제목과 작은 부제, 반복 소개 정리

공통 C 헤더를 각 화면의 주 제목으로 사용하고, 본문에서 같은 역할을 하는 제목·소개 블록을 제거한다.

## 변경

- 한글 주 제목을 PC 32px, 모바일 28px로 확대한다. 영문 부제는 10px이다.
- 헤더 기본 높이는 PC 80px, 모바일 72px이며 오른쪽 흑백 사진과 붉은 선 아이콘을 유지한다.
- 제목 폭을 넓히고 말줄임을 제거해 긴 하위 화면 제목도 읽을 수 있도록 한다.
- 홈의 큰 홍보 배너와 중복 운동 시작 버튼을 제거한다. 실제 현재 운동 카드와 상태별 진입 동작을 유지한다.
- 운동·도감·성과·변화 그래프의 반복 본문 제목과 소개 블록을 제거한다.
- 루틴·프로그램·운동 기록 화면은 주 제목 아래에 개수와 기존 작업 버튼을 간결하게 배치한다.
- 기존 루틴을 편집할 때 주 제목을 '루틴 수정'으로 표시한다.
- 그래프와 관련 화면의 접근성 이름은 공통 제목 ID에 연결한다. 개별 그래프 제목·단위·계산 기준은 유지한다.
- 변경한 파일의 캐시 버전과 표시 버전을 0.8.9로 올린다.

## 검증

- 변경한 JavaScript 3개 문법 검사 통과.
- 기존 `iron.test.cjs`, `progress.test.cjs` 27건과 `iron-independent.test.cjs` 37건 통과, 합계 64건·실패 0건.
- 제거한 소개 문구로 홈 진입을 판별하던 기존 테스트 2곳은 실제 홈 탭 선택 상태를 판별하도록 갱신한다. 운동 진입 테스트 이름도 현재 경로에 맞게 정리한다.
- Git 변경분 공백 검사 통과.
- 배포 후 브라우저에서 제목·사진·중복 영역 제거와 주요 탐색 동작을 확인한다. 실제 iPhone 기기 테스트 결과를 의미하지 않는다.

저장소 스키마·Firebase 인증·동기화·운동 세션 저장 로직은 변경하지 않는다.
