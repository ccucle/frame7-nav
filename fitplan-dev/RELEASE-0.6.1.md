# FORMDAY v0.6.1 — 기록 기능 수정과 테마 통일

작성: 2026-11-24 (한국 시간)

대상은 기존 `fitplan-site-20261123` 브랜치와 Render의 `formday-fitplan-ccucle` 정적 사이트다. 기준 커밋은 `48df594426f695a75f2fcbf1a3a1b3b8585f1df9`다.

## 사용자에게 보이는 변경

- **웨이트 종목 추가:** 진행 중인 세션에 추가한 세트가 유효한 미완료 상태로 생성되어 저장된다.
- **미완료 운동 취소:** 진행·일시정지·임시 보관 중인 운동을 확인 후 취소할 수 있다. 완료 세트가 있으면 취소 시 지워질 수량과 부분 완료 대안을 안내한다. 완료 기록, 루틴, 프로그램 및 주기 진행은 취소 대상에서 제외한다.
- **루틴·프로그램 초안:** 바뀐 초안을 두고 이동하거나 취소할 때 확인한다. 취소한 초안이 나중에 되살아나지 않으며, 확인창에서 이동을 거부하면 입력을 보존한다.
- **통계 연결:** 기존 캘린더 웨이트와 독립 IRON MODE의 완료·부분 완료 세션을 읽어 대시보드, 운동 성과 및 선택 날짜 요약에 합산한다. 두 저장소의 원본을 이동·합치거나 다시 저장하지 않는다.
- **집계 기준:** 실제 완료된 본세트의 중량 × 횟수만 운동량에 합산한다. 워밍업, 체험용 샘플, 미래 기록, 루틴 목표와 미완료 세션은 실제 운동 통계에서 제외한다. 식단·체중 요약도 샘플과 미래 기록을 제외한다.
- **백업 복원:** 기기 동기화 창에서 내려받은 JSON도 각 저장소의 기존 가져오기 기능으로 복원할 수 있다. 이전 `FORMDAY-cloud-manual-backup` 파일은 종류와 내용 검증 후 지원한다.
- **화면 이동:** 통계 갱신이 작성 중인 독립 웨이트 화면을 바꾸지 않는다. 미니 캘린더 날짜를 선택하면 날짜 DOM이 갱신되어도 캘린더 화면으로 이동한다.
- **동기화 안내:** 이미 제공 중인 Google 계정 동기화에 맞춰 예전 준비 중 문구를 수정한다.

## 테마와 모바일 구성

`fitplan/theme.css`를 기존 기능 스타일 뒤에 적용한다. 어두운 배경, 밝은 본문, 붉은 주요 버튼, 초록 완료 표시를 공통 기준으로 사용한다. 운동·캘린더·식단·백업·계정·동기화 창의 카드, 입력창, 테두리, 여백을 맞춘다.

주요 버튼은 최소 44px, 숫자 입력은 16px 기준으로 정리했다. 좁은 화면의 운동 세트는 숫자 입력과 완료·저장을 두 줄로 나누며, 하단 메뉴와 액션에 safe-area 여백을 반영했다. 중량·RPE는 소수, 횟수·휴식은 숫자 키보드를 요청한다. 주간 캘린더의 밝은 머리글과 중간 화면 너비의 빈 열도 수정했다.

## 동기화 계정 경계 보호

동기화 요청은 시작 계정 UID와 로그인 세대를 고정한다. 다운로드, 트랜잭션 읽기·재시도·완료 및 구독·타이머가 반환될 때 계정 상태가 같아야 결과를 적용한다. 이전 로그인 상태의 늦은 응답이나 오류가 새 계정의 로컬 기록·소유자 메타데이터·진행 상태를 변경하지 않는다.

기존 Firebase 프로젝트 설정, 인증 방식, Firestore 경로·보안 규칙, 로컬 저장 키 및 저장 스키마 버전은 변경하지 않는다. 새로운 클라우드 서비스나 요금제를 만들지 않는다.

## 배포 전 검증


수정된 JavaScript 문법 검사와 `git diff --check`도 통과했다. 자동 테스트는 모의 저장소·인증·Firestore 응답으로 실행했다. 계정 변경 경계는 지연 Promise로 로그아웃, 다른 계정 전환, 같은 계정 재로그인, 트랜잭션 재시도와 늦은 오류를 검증했다. 사용자 Firebase 기록을 테스트 자료로 사용하지 않았다.

로컬 개발 주소는 점검 브라우저에서 접근할 수 없어 배포 전 시각 검증은 수행하지 못했다. 화면·버튼 확인은 배포 후 기존 공개 주소에서 진행한다. 자동 테스트 및 정적 반응형 검토는 실제 아이폰 기기에서의 렌더링·Google 로그인·두 기기 동기화 검증을 대체하지 않는다.
