# FORMDAY v0.8.8 — 아이콘과 사진을 결합한 탭 제목

사용자가 승인한 C안의 작은 붉은 선 아이콘, 한글 제목과 영문 부제, 오른쪽 흑백 사진을 공통 탭 헤더에 적용한다.

## 변경

- 홈: 오늘의 기록 / TODAY, 운동: 오늘의 운동 / WORKOUT.
- 캘린더: 통합 캘린더 / CALENDAR, 그래프: 몸의 변화 / PROGRESS.
- 도감: 운동 도감 / LIBRARY, 성과: 훈련 성과 / PERFORMANCE.
- 루틴·프로그램 편집 등 하위 화면은 현재 작업을 나타내는 제목을 유지한다.
- 헤더 높이는 PC 72px, 모바일 64px, 제목은 각각 22px·20px이다.
- 오른쪽 사진은 헤더 폭의 30%를 사용하고 어두운 흑백·페이드 효과로 제목과 분리한다.
- 6개 생성 사진을 로컬 WebP로 제공한다. 합계 50,962바이트로 외부 사진 서버 요청을 추가하지 않는다.
- 홈 전용 6개 빠른 메뉴의 DOM과 동작을 유지한다. 화면 전환 시 제목·영문 부제의 텍스트만 갱신한다.
- 변경한 스크립트와 새 CSS의 캐시 버전, 표시 버전을 0.8.8로 갱신한다.

## 확인 범위

- 변경한 두 JavaScript 파일의 문법 검사 통과.
- `node --test fitplan-dev/iron.test.cjs fitplan-dev/iron-independent.test.cjs`: 기존 화면 전환·독립 운동 테스트 54건 통과, 실패 0건. 사진 표시 자체를 검증하는 테스트는 아니다.
- Git 변경분 공백 오류 없음. 로컬 이미지 경로 6개 확인.
- 배포 후 실제 브라우저에서 6개 탭의 제목·사진·아이콘과 홈 전용 메뉴 표시를 확인한다.
- 실제 iPhone 기기 확인은 별도이다. 모바일 크기는 반응형 CSS에 반영한다.

Firebase 인증·보안 규칙·동기화 및 기록 저장 코드는 변경하지 않는다. 기존 Render 정적 사이트에 배포하며 새 리소스를 생성하지 않는다.
