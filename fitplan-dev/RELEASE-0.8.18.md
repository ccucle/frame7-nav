# FORMDAY v0.8.18 — 훈련 프로그램 수정

- 프로그램 목록의 기존 항목에 '프로그램 수정' 버튼을 추가한다.
- 이름, 순환/요일 고정 방식, 루틴 추가/제외, 순서(위·아래), 요일 배치를 수정할 수 있다.
- 선택된 루틴만 요일에 배정하며, 제외된 루틴의 요일 배치는 제거한다.
- 기존 프로그램 ID 및 활성 상태를 유지하고, 순환형의 다음 루틴이 남아 있으면 ID 기준으로 위치를 보존한다. 없으면 첫 루틴으로 전환한다.
- 이미 시작한 세션 및 과거 기록은 변경하지 않는다. 저장 및 충돌 확인은 기존 저장소를 사용한다.
- 프로그램 수정 전용 회귀 테스트를 추가했다. 전체 테스트 실행은 별도 검증이 필요하다.
