# FORMDAY v0.8.34 — 식단 코멘트 표시 및 편집

- 기존 formday-ai-meal-v1의 notes를 사용해 음식별, 식사별, 확인된 일일 평가 및 사용자 메모를 함께 가져온다.
- 미리보기에서 줄바꿈을 보존하고, 날짜 상세에서 각 식사의 코멘트·메모를 펼쳐 읽는다.
- 일반 식단 편집에서도 메모를 입력하며 선택적으로 음식명 기반 코멘트 양식을 추가한다. 기존 메모 보존, 중복 양식 방지, 2,000자 초과 시 변경 거부.
- 기존 스키마/저장·동기화 구조, 영양 집계, 중복 방지 및 데이터 보호 유지. 사용자 입력은 평문으로만 표시. 저장 후 notes 일치 확인.
- ChatGPT Connect v0.2.5의 기존 notes 형식과 호환. 사이트 자체 AI API, 원본 사진, 신규 서버·과금은 추가하지 않는다.
- 일반 ChatGPT에서 직접 호출 가능한 MCP 연결은 별도 미해결 과제. 자동 등록 및 실제 계정 동기화는 이 변경만으로 검증되지 않는다.
