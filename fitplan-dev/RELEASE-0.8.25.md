# FORMDAY v0.8.25 — 웹앱 아이콘

- 기존 A안 Power F SVG와 동일한 흰색 경로·붉은 그라데이션에서 PNG 아이콘을 생성. 홈 화면용은 운영체제 마스킹에 맞게 모서리까지 불투명 배경 사용.
- iOS apple-touch-icon 180×180, 웹앱 매니페스트 아이콘 192×192·512×512, 일반 브라우저 PNG 32×32 폴백 제공.
- 기존 서비스 주소, 기록 저장소, 인증 및 동기화 코드는 변경하지 않음. 서비스 워커는 추가하지 않음.
- 기존 설치 아이콘의 갱신은 운영체제 캐시 정책에 따르며 재등록이 필요할 수 있음. 로컬 기록 보존을 위해 기존 웹앱 제거 전에 두 저장소를 백업하고 동기화 상태를 확인해야 함.
- PNG 서명, 크기, CRC 및 압축 데이터 왕복 확인. 실제 설치 기기 아이콘 갱신은 별도 검증 필요.
