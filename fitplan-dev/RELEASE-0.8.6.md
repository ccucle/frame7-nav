# FORMDAY v0.8.6 — 터치 후 남는 포커스 테두리 제거

운동 이어하기 버튼과 운동창 손잡이에 터치·창 열기·닫기 이후 남던 추가 포커스 테두리를 숨긴다.

## 변경 내용

- 포인터 입력은 캡처 단계에서 감지해 이후 자동 포커스 이동에도 추가 테두리가 나타나지 않게 한다.
- 손잡이 막대 주위의 작은 회색 포커스 테두리에도 같은 규칙을 적용한다.
- Tab·방향키 등 키보드 이동을 사용하면 기존 포커스 표시를 다시 제공한다. 휴대폰에서 문자를 입력하는 것만으로 키보드 이동 모드로 전환하지 않는다.
- 실제 포커스 이동, 대화상자, 기본 버튼 테두리, 입력창 편집 표시, 완료 상태는 유지한다.
- 공유 테마와 운동창 CSS 캐시 및 표시 버전을 갱신한다. 운동 기록·타이머·동기화 코드는 변경하지 않는다.

## 확인 범위

새 스크립트 문법과 변경분을 검사하고, 배포 후 브라우저에서 버튼·손잡이의 포인터 포커스와 키보드 전환을 확인한다. 실제 iPhone 기기 검증은 별도이다.

기존 Render 정적 사이트를 갱신하며 새 리소스를 만들지 않는다.
