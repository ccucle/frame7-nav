## 확인 범위와 남은 제한

- 실제 UI 조작은 데스크톱 Chrome에서 확인했습니다. iPhone/Safari 실기기 검증은 수행하지 않았습니다.
- 모바일 CSS와 입력 크기는 구현했으며, 실기기 키보드·터치·화면 회전은 추가 확인 대상입니다.
- 저장 공간 접근 거부·쓰기 실패 및 백업 복원은 자동 테스트로 확인했으며, 브라우저 저장소를 강제로 손상시키는 실험은 하지 않았습니다.
- 영양 데이터의 출처 검증이나 전체 식품 DB 연결은 이번 범위에 포함하지 않았습니다. 화면에 샘플 데이터임을 표시합니다.
- 비반복 일정의 편집창 안에서 날짜를 바꾸면 '지난 기록' 참고 목록은 창을 처음 열었던 날짜 기준입니다. 날짜를 먼저 선택한 뒤 편집창을 여는 흐름은 정상이며, 저장되는 일정 날짜·기록에는 영향을 주지 않습니다. 다음 UI 개선 시 참고 목록의 즉시 갱신을 추가할 수 있습니다.
