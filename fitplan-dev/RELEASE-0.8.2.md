# FORMDAY v0.8.2 — 한 줄 세트와 작은 휴식 타이머

사용자 참고 이미지의 구조에 맞춰 운동 기록을 한 줄로 정리하고, 세트 완료 뒤 하단에서 올라오는 작은 휴식창을 제공한다.

## 세트 입력

- 세트 번호, 중량과 kg, 횟수와 회, 원형 완료 버튼을 4열 한 줄로 유지한다.
- 모바일에서는 68px 행과 44px 이상의 주요 조작 영역을 사용한다. 입력칸은 기본적으로 평평한 형태이며 초점이 있을 때 테두리로 구분한다.
- 종목의 더보기 버튼에서 세트별 휴식 시간과 RPE 상세 설정을 펼친다. 기본 목록에서는 상세 행을 숨긴다.
- 개별 완료와 전체 완료를 각각 SVG 체크와 이중 체크로 표시한다. 접근성 이름과 눌림 상태를 유지한다.

## 휴식 타이머

- 세트 완료 저장이 성공하면 해당 세트의 설정 시간으로 휴식이 시작된다. 0초로 설정한 세트는 자동 휴식을 표시하지 않는다.
- 작은 하단 패널이 올라오며, 목표 휴식 시간, 진행 막대, 큰 `mm:ss`, 소리 켜기/끄기, 닫기, 일시정지/재개, −10초/+10초를 제공한다.
- 목표 시간 버튼에서 30·60·90·120초를 선택해 현재 휴식을 다시 시작할 수 있다. 이 선택은 이번 타이머에만 적용하며 루틴의 저장된 목표를 바꾸지 않는다.
- ±10초는 남은 시간에 적용하고 0~600초로 제한한다. 일시정지한 타이머는 시간 조절 후에도 정지 상태를 유지한다.
- 타이머를 닫아도 완료한 세트 기록은 유지한다. 해당 타이머를 시작한 세트의 완료를 해제하면 타이머도 닫힌다. 다른 세트의 해제는 최신 타이머를 취소하지 않는다.
- 타이머 조작은 운동 입력 필드를 재생성하지 않는다. 닫기 중 새 휴식이 시작되면 이전 닫기 콜백을 무효화한다.
- 완료 시 짧은 알림음 두 번을 한 알림으로 재생한다. 사용자 조작에서 Web Audio를 준비하고, 소리를 끄거나 오디오 사용이 불가능해도 기록과 타이머는 동작한다. 이미 끝난 휴식은 다시 열었을 때 늦게 울리지 않는다.
- 앱 전환·운동 일시정지 시 휴식도 정지한다. 사용자가 휴식만 별도로 멈춘 경우 운동 재개가 이를 자동으로 재시작하지 않는다.
- `pagehide` 임시 저장 실패 경로에서도 백그라운드 시간을 운동·휴식 시간에 더하지 않도록 동결한다.
- 기존 운동 바텀시트, 내부 스크롤, 세트·메모 저장, Firebase 동기화 형식은 유지한다.

- 검증 범위: 자동 휴식, 시간 조절·경계값, 일시정지, 타이머 출처에 맞는 완료 해제, 전체 완료·해제, 입력 보존, 닫기 경쟁, 애니메이션 재실행 방지, 소리 중복·지연 방지, 상세 설정, 저장 실패 시 시간 동결.
- JavaScript 문법과 `git diff --check` 확인.
- 자동 DOM 검증과 실제 iPhone 기기의 터치·키보드·소리 동작 검증을 구분한다. 실제 기기 검증은 완료로 표시하지 않는다.
