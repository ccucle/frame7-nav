# FORMDAY v0.8.24 — 실제 운동 검토 및 부위별 그래프

- 확정 세션이라도 실제 완료 세트가 없거나 미래 날짜 또는 명시적 샘플이면 운동 기록 집계에서 제외하고 원본은 확인 필요 목록에 보존한다.
- `[TEST]` 이름은 검토 필요로 표시하되 이름만으로 삭제하거나 집계에서 제외하지 않는다. 기록 상세에 출처, 시작/종료 시각 및 ID 표시.
- 샘플 속성은 기존 독립 기록 정규화에서도 보존. 미래 예정 운동 시작/완료 차단, 캘린더의 전체 세트 완료에 재확인 추가.
- 기존 7/30/90/전체 기간에 부위별 총 운동량(kg×횟수), 완료 본세트, 최고 사용 중량 비교·날짜 그래프를 추가. 기존 도감 주 부위 분류, 미분류 기타. 실제 기록만 집계, 연결된 캘린더/세션 중복 방지 기존 로직 재사용, 미기록은 비움. 장기간 구간 합계/최댓값.
- 실제 사용자 Firebase/아이폰 기록에는 접근하지 못했으므로 구체적인 잘못된 기록의 출처나 삭제 여부는 확인하지 못했다. 개인 기록 삭제·수정은 하지 않았다.
