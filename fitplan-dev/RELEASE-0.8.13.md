# FORMDAY v0.8.13 — 캘린더 운동 연결과 날짜별 루틴 교체

## 사용자 동작

- 운동 탭의 `예정된 운동`에서 날짜를 선택해 캘린더 웨이트 일정을 확인한다. 종목과 세트를 미리 보고 그 일정으로 운동을 시작할 수 있다.
- 캘린더 날짜 상세에서도 운동 시작·이어하기·확정 기록 열기를 제공한다. 홈의 오늘 운동 카드도 미완료 캘린더 계획으로 바로 시작한다.
- 일정에 등록한 종목 순서, 세트 수, 중량, 횟수, 워밍업, RPE, 기존 완료 체크와 보관된 메모를 실행 세션에 그대로 복사한다. 캘린더에 휴식 시간이 없는 경우 기존 기본값 90초를 사용한다.
- 같은 일정 ID와 날짜로 다시 열면 기존 운동을 재개한다. 재로드 후 임시 보관된 상태도 재개하며 중복 세션을 만들지 않는다.
- 운동 완료·부분 완료는 독립 운동 기록을 먼저 확정한 뒤 원래 캘린더 날짜에 실제 세트를 반영한다. 일부 세트만 수행했다면 나머지를 자동 완료하지 않는다.
- 일정 옆 교체 아이콘으로 저장된 다른 루틴을 선택하고 `이 날짜에 적용`한다. 모바일에서는 선택창이 아래에서 올라온다. 원래 루틴, 반복 기본 계획과 다른 날짜는 변경하지 않는다.
- 이미 시작했거나 실제 완료 세트가 있는 일정은 교체를 막는다. 진행 중 운동의 개별 종목 추가·교체 기능은 기존 동작을 유지한다.

## 저장과 충돌 처리

- 기존 두 저장소와 Firebase 문서를 그대로 사용한다. 새 데이터베이스, 컬렉션, 유료 서비스, 인증·보안 규칙 변경은 없다.
- 선택적 `calendarSource`와 날짜별 `workoutSessionId`가 기존 정규화·백업·동기화를 통과한다. 기존 레코드에는 연결 정보를 자동 생성하지 않는다.
- 시작 시점의 일정 내용과 현재 내용을 비교한다. 운동 중 일정이 바뀌거나 삭제됐으면 확정된 운동은 보존하고 캘린더를 덮어쓰지 않는다.
- 캘린더 저장 실패 시 기록 화면에서 명시적으로 다시 반영할 수 있다. 같은 연결 ID로 재시도하면 중복 저장하지 않는다. 시작·재로드 시 자동 재시도로 사용자의 삭제/되돌리기를 취소하지 않는다.
- 연결된 결과는 하루 요약·주간 운동량·기록 분석에서 한 번 집계한다. 반영 대기 중에도 원래 계획이 그대로면 확정 운동을 한 번만 사용한다. 서로 충돌하는 실제 수정 내용은 임의로 숨기지 않는다.
- 교체 창을 연 동안 클라우드 자동 적용을 미루고, 적용 직전에 독립 운동 저장소 revision과 선택한 루틴 내용을 재확인한다.
- 결과가 연결된 완료 일정의 날짜·종류 이동을 차단한다. 제목·세트 편집은 기존 편집 경로를 이용한다.
