# FORMDAY v0.8.5 — 운동 슬라이드 창 전체 화면

운동 진행창이 아래에서 올라온 뒤 브라우저 표시 영역 전체를 채우도록 변경한다.

## 변경 내용

- 창 위에 남던 6%/36px 간격과 둥근 상단 모서리를 제거한다.
- native dialog에 화면 전체 너비와 `100dvh` 높이를 적용하고, `100vh` 대체값을 유지한다.
- 상단 안전 영역은 창 높이에서 빼는 대신 고정 헤더 안에 둔다. 가로 화면의 좌우 안전 영역과 기존 하단 안전 영역을 반영한다.
- 손잡이 전체 너비에 나타나던 핑크색 포커스 테두리를 제거한다. 키보드 포커스는 작은 회색 손잡이 막대에 표시한다. 다른 조작 요소의 포커스 표시는 유지한다.
- PC 본문은 기존 최대 900px 너비를 유지하며 하단 종목 추가·휴식창을 화면 가운데 정렬한다.
- 아래에서 올라오는 애니메이션, 아래로 내려 닫기, 내부 스크롤, 외부 컨테이너의 `overflow: clip`을 유지한다.

## 범위와 확인

- 변경은 운동창 CSS와 CSS 캐시·표시 버전에 한정된다.
- `git diff --check` 통과. 기존 기록·타이머 JavaScript 및 Firebase 설정은 변경하지 않는다.
- 실제 iPhone 기기의 터치·상태 표시줄·키보드 검증은 포함하지 않는다.

기존 Render 정적 사이트를 갱신하며 새 리소스를 만들지 않는다.
