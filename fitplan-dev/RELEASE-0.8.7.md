# FORMDAY v0.8.7 — 홈 전용 아이콘 메뉴

공통 상단의 계정·기기 동기화·무료 백업·목표 설정·식단 기록·새 일정 버튼을 홈 대시보드에서만 표시한다.

## 변경

- 큰 텍스트 버튼 6개를 같은 선 두께의 SVG 아이콘 버튼 한 줄로 정리한다.
- 각 버튼의 터치 영역은 44×44px, 간격은 6px이다. 전체 294px로 320px 화면의 기존 본문 내부 폭 296px에 들어간다.
- 홈 이외의 운동·캘린더·그래프·도감·성과 화면에서는 메뉴 전체가 숨겨진다.
- 기존 버튼 ID와 클릭 동작을 유지하며 접근성 이름과 마우스 설명을 제공한다.
- 로그인 상태가 바뀔 때 계정 아이콘이 지워지지 않도록 접근성 이름·설명·로그인 표시만 갱신한다. 로그인됨은 작은 녹색 점으로 표시한다.
- 테마·인증 화면 스크립트 캐시와 표시 버전을 갱신한다.

## 확인

- `node --check fitplan/cloud-auth.js` 및 변경분 공백 검사 통과.
- `node --test fitplan-dev/ios-pwa-auth.test.cjs`: 8개 통과. 초기 상태·모의 로그인·로그아웃마다 SVG 보존과 접근성 이름·로그인 표시 갱신을 확인한다.
- 새 회귀 검사가 기존 `textContent` 교체 코드에서 실패하는 것도 확인했다. 실제 계정은 사용하지 않는다.
- 배포 뒤 홈 아이콘 표시, 다른 화면에서 숨김, 기존 메뉴 열기를 브라우저에서 확인한다. 실제 iPhone 기기 검증은 별도이다.

인증 흐름, Firebase 규칙, 동기화 및 기록 저장 방식은 변경하지 않는다. 기존 Render 정적 사이트를 갱신하며 새 리소스를 생성하지 않는다.
