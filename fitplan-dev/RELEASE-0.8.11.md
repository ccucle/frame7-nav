# FORMDAY v0.8.11 — 캘린더 날짜 상세

캘린더에서 오늘 날짜를 선택하면 캘린더 아래의 오늘 상세로 스크롤한다. 다른 날짜를 선택하면 하단에서 올라오는 상세 창에 같은 상세 영역을 표시한다. 월·주·일 보기와 미니 캘린더에 같은 동작을 적용한다.

## 화면과 등록

- 오른쪽 고정 패널을 없애고, 상세 패널 하나를 인라인과 native dialog 사이에서 이동한다. 날짜 제목·요약·일정·웨이트 진행·식단 영양·최근 체중을 한곳에 배치한다.
- 웨이트·유산소·식단·체중 등록에 보고 있는 날짜를 전달한다. 기존 등록 폼을 열 때 날짜 dialog는 잠시 닫고, 저장·취소 후 해당 상세로 돌아온다.
- 저장한 루틴을 기존 캘린더의 날짜별 운동 계획으로 가져올 수 있다. 새 운동·세트 ID를 만들고 완료 상태를 초기화하며 원본 루틴은 유지한다.
- 기존 반복 일정의 날짜별 수정, 충돌 감지, 저장 실패 시 초안 유지와 백업 동작을 그대로 사용한다.
- 완료한 IRON 운동은 기존 데이터에서 해당 날짜만 조회한다. 동일 기록을 복제하거나 새로운 데이터베이스·저장소를 만들지 않는다.
- 오늘 상세의 예약된 스크롤이 등록 폼의 포커스를 방해하지 않게 하고, dialog 안에도 저장 결과·오류를 표시한다.

## 검증

- 변경 JavaScript 문법 검사와 `git diff --check`.
- `fitplan-dev/app.test.cjs`: 날짜 전달, 동일 DOM 이동, 읽기 전용 날짜 이동, 등록 후 복귀, 반복 일정의 한 날짜 수정, 저장 실패·재시도, 루틴 원본 보존 검증.
- 기존 core·workouts·iron·session-screen·cloud-sync 테스트로 저장·통계·운동 실행·동기화 회귀 점검.
- 배포 후 실제 브라우저에서 오늘 이동, 다른 날짜 상세 창, 등록 폼 날짜와 취소 복귀, 미니 캘린더 이동을 확인한다. 실제 계정에 시험 기록을 저장하지 않는다.

Firebase 스키마·보안 규칙·로그인·클라우드 동기화 프로토콜은 변경하지 않는다. 새 유료 리소스도 추가하지 않는다.
