# FORMDAY v0.8.15 — 운동 도감·기록 메뉴 재배치

- 최상위 PC 메뉴와 모바일 하단 메뉴에서 운동 도감을 제거한다. 모바일 하단은 홈·운동·캘린더·그래프의 4개 메뉴를 사용한다.
- 운동 하위 메뉴는 운동·루틴·프로그램·운동 도감으로 통일한다. 도감 검색·필터·운동 시작은 기존 도감 렌더러에서 처리하며, 도감에서도 최상위 운동 메뉴가 선택된다.
- 기존 운동 기록 목록과 상세를 그래프의 마지막 영역으로 옮긴다. 그래프의 기간 선택과 별도로 전체 확정 운동 기록을 표시한다.
- 운동 완료, 캘린더에서 완료 세션 열기, 기록 선택은 그래프 하단의 해당 기록으로 이동한다. 기록에서 새 루틴 저장·기존 루틴 반영·캘린더 재반영 기능은 기존 처리기를 그대로 사용한다.
- 기록 host는 그래프 host 다음 형제 요소이므로 그래프 기간·크기 변경 시 사라지지 않는다. 운동 탭의 최근 기록 중복 영역은 제거한다.
- 저장소, 실제 기록, Firebase 동기화 및 보안 규칙은 변경하지 않는다.

검증: 기존 대시보드·운동·실행 화면·그래프 테스트 112개 통과, 실패 0개. 기존 완료 테스트에서 실제 iron.js와 iron-independent.js를 함께 실행하여 그래프 전환, 상세 선택, 데이터 갱신 및 확정 기록 보존을 확인했다. JavaScript 문법 검사와 git diff --check 통과. 실제 아이폰 Safari 검증과 브라우저의 좁은 화면 확인은 구분한다.
