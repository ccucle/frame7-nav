# FORMDAY v0.8.10 — 홈의 기존 이미지 배너 복원

사용자가 유지하기를 원한 홈의 큰 이미지 배너를 복원한다. v0.8.8의 사진, '오늘도 기록 갱신하자.' 문구, 소개와 운동 시작/이어하기 버튼, 사진 출처를 그대로 사용한다.

v0.8.9의 확대된 공통 제목과 작은 영문 부제, 다른 화면의 중복 제목 정리는 유지한다. 변경 범위는 홈 배너 렌더링과 버전·캐시 참조다.

## 확인

- 기존 v0.8.8 홈 배너 마크업과 정확히 일치하는지 비교 완료.
- 변경한 JavaScript 문법 검사 통과. 기존 운동 대시보드·탐색 테스트 17건 통과, 실패 0건.
- 배포 후 홈 화면에서 사진·문구·버튼을 확인한다.

개인 기록·인증·동기화·저장 로직에는 변경이 없다.
