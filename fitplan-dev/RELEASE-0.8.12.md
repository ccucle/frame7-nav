# FORMDAY v0.8.12 — 일정 입력 정리와 모바일 웨이트 레이아웃

## 변경

- 일정 등록·수정에서 유산소, 식단, 체중은 일정 제목 입력란을 표시하지 않는다.
- 새 유산소는 종목명, 식단은 첫 음식명과 추가 음식 수, 체중은 `체중 측정`으로 제목을 만든다.
- 같은 유형의 기존 기록을 수정할 때는 원래 제목을 보존한다. 반복 일정의 기본 제목과 날짜별 스냅샷 제목도 각각 보존한다.
- 웨이트는 직접 제목을 입력하거나 저장한 루틴 이름을 사용한다. 유형을 바꿔도 웨이트의 임시 제목이 다른 유형의 기록에 섞이지 않는다.
- 유산소·식단·체중 폼의 초기 포커스는 창 제목에 둔다. 숨은 필드에 포커스를 보내거나 모바일 키보드를 자동으로 띄우지 않는다.
- 날짜·반복과 시작·종료 시간을 균일한 2열로 정돈하고, 모바일 native date/time의 너비 제한을 명시한다.
- 좁은 화면의 웨이트 세트는 `번호 / 중량 / 횟수 / 완료`, 그 아래 `RPE / 세트 종류 / 복제·삭제`로 정렬한다. 입력 16px, 주요 터치 영역 최소 44px을 유지한다.
- 새 스타일은 `.fd-event-form`에 한정한다. 운동 실행 화면과 다른 모달에는 적용하지 않는다.
