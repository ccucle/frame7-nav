# FORMDAY v0.8.21 — 충돌 복구

- 두 저장소의 기기/서버 기록을 사용자 확인 하에 비교 및 병합. 동일 ID는 비교, 다른 ID는 보존. 공통 버전이 확인되는 경우 변경/삭제를 3-way 비교. 공통 버전이 없을 경우 삭제된 항목이 다시 포함될 수 있음을 표시.
- 같은 ID의 변경 충돌은 개별 선택이 필요하며, 검증 실패 시 저장을 막는다.
- 동일 내용은 원본 변경 없이 버전 연결만 복구한다.
- 병합 전에 양쪽 스냅샷을 기기에 저장하고, 저장 실패 시 서버 쓰기 중단. 계정, 로컬 버전, 서버 문서, 편집 상태 재확인. 서버 쓰기 이후 로컬 적용에 실패하면 원본을 보존하고 재비교 안내.
- 기존 서버 경로, Firestore 규칙 및 요금제 유지. 실제 사용자 데이터에는 직접 접근하지 않는다.

- 임시 보관·일시정지 상태는 편집 창이 닫혔고 활성 세션이 없을 때에만 병합 가능하다. 복구 시 완료를 강제하지 않는다.
- 서로 다른 병합 원본은 이전 복구 사본을 유지하고, 저장 공간이 부족할 경우 병합을 중단한다. 개별 원본 다운로드를 제공한다.
