# FORMDAY 무료 파일 백업 · v0.3.1

사용자가 추가 운영비를 지불하지 않겠다는 조건을 확정하여 유료 Render 계정 서버·DB 도입을 철회했습니다.

## 실제 작동 방식
- 기존 v0.3 식단·웨이트·체중·캘린더 기록을 그대로 유지합니다.
- 상단의 **☁ 무료 백업** 버튼은 현재 브라우저에서 저장된 실제 데이터만 읽어 기존 v3 JSON 백업 파일을 만듭니다.
- iPhone Safari 등 파일 공유를 지원하는 환경에서는 공유 메뉴를 호출합니다. 사용자가 **파일에 저장 > iCloud Drive**를 선택하고 실제로 저장됐는지 파일 앱에서 확인해야 합니다.
- 공유가 불가능하면 브라우저의 파일 다운로드로 전환합니다. 사용자가 iCloud Drive 또는 Google Drive로 옮겨야 합니다.
- **백업 파일로 복원**은 기존 사이트의 가져오기 기능을 호출하며 대상 기록을 대체할 때 사용자 확인을 받습니다.
- 브라우저에 기록이 없거나 기록 저장 형식이 손상되면 백업 생성을 막고 오류를 보여 줍니다. 원본 기록을 덮어쓰지 않습니다.
- 다운로드/공유 API가 실행됐다는 사실을 클라우드에 보관 완료됐다는 사실로 표현하지 않습니다.
- 이번 버전은 **자동 백업도 자동 기기 동기화도 아닙니다**. 클라우드 연결용 OAuth나 무료 계정 API를 등록하지 않습니다.
- 내보낸 JSON에는 건강 정보가 포함되며 **파일 자체는 암호화되지 않습니다**. 공유 대상에 주의해야 합니다.

## 무료 저장 공간(일반 정책)
- iCloud Drive: 무료 iCloud 5GB, Apple 계정의 다른 데이터와 공유.
- Google Drive: Google 계정당 최대 15GB, Gmail과 Photos 등의 데이터와 공유.
- 무료 공간이 부족하거나 서비스 정책이 바뀌면 백업이 되지 않을 수 있으며, 이 경우 요금제 업그레이드로 해결하지 않습니다.

공식 안내:
- https://support.apple.com/ko-kr/108047
- https://support.apple.com/en-euro/guide/iphone/iphbbcf8827d/27/ios/27
- https://support.google.com/accounts/answer/6374270?hl=en
- https://developer.mozilla.org/en-US/docs/Web/API/Web_Share_API

## 테스트
- 백업 파일 형식과 실제 값 보존
- 빈 로컬 저장소/손상 파일 거부
- 기존 식사 기록과 영양 정보의 v3 마이그레이션 보존
- 성공 메시지를 클라우드 저장 완료로 오해하지 않도록 UI 문구 검사

실제 iPhone Safari에서 공유 시트의 '파일에 저장' 항목을 선택하는 사용자의 최종 동작은 개발자가 대신 수행할 수 없습니다. 따라서 최초 백업은 파일 앱에서 직접 확인이 필요합니다.
