# FORMDAY v0.8.20 — 훈련 프로그램 캘린더 등록

- 프로그램 카드에 캘린더 등록 버튼과 날짜·시간·미리보기 창을 추가한다.
- 순환형은 지정한 시작일부터 저장된 순서의 각 루틴을 하루에 한 번씩, 총 루틴 수만큼 등록한다.
- 요일 고정형은 기존 캘린더의 일요일~토요일 주간 기준으로 지정 요일만 한 주 등록한다. 이번 주/다음 주 버튼을 제공한다.
- 기기 현지 오늘 날짜를 등록할 때 다시 계산하며 과거 등록을 거부한다. 이번 주의 지난 요일은 제외한다.
- 해당 날짜에 같은 제목의 실제 웨이트 일정이 있으면 건너뛴다. 기존 일정은 수정하지 않는다. 등록 전에 최신 프로그램 및 루틴과 미리보기 정합성을 확인한다.
- 기존 캘린더 저장소에서 한 번의 검증·커밋으로 저장한다. 루틴/프로그램 원본 및 실제 운동 기록, 순환 진행 위치를 변경하지 않는다. 일정은 기존 운동 시작 및 루틴 교체 흐름을 사용한다.
- 기존 캘린더 세트 형식을 사용한다(별도의 휴식 시간 저장 필드는 추가하지 않음).
- 프로그램 등록 회귀 검사 추가.
