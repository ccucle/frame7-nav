# FORMDAY v0.8.3 — 운동 화면 글씨와 간격 축소

휴대폰에서 세트 기록을 볼 때 스크롤이 길다는 피드백에 따라 운동 진행창의 글씨와 여백을 줄인다.

## 화면 변경

- 600px 이하 화면: 운동 제목 28→22px, 종목명 18→16px, 중량·횟수 24→20px, 상단 지표 25→20px.
- 세트 한 줄의 최소 높이를 모바일 68px·데스크톱 72px에서 56px로 줄인다. 세트 번호·무게·횟수·완료의 한 줄 배치는 유지한다.
- 고정 상단, 종목 카드, 이미지, 메모 주변과 세트 조절 도구의 간격을 줄인다.
- 휴식 카운트다운은 48→38px(360px 이하 36px)로 줄이고 패널의 세로 여백도 줄인다. 목표 시간·알림음·닫기·일시정지·±10초는 유지한다.
- 주요 버튼은 최소 44px, 메모 입력 글씨는 16px을 유지한다.
- 바깥 dialog의 `overflow: clip`, 내부 목록 스크롤, 하단 안전 영역, 감소된 모션 설정을 유지한다.

## 변경 범위

- 운동 화면 CSS와 해당 CSS 캐시 버전·표시 버전만 변경한다.
- 기록 저장·타이머 JavaScript, Firebase 연결과 데이터 구조는 변경하지 않는다.
- 실제 iPhone 기기에서의 터치·키보드 검증은 이 릴리스에 포함하지 않는다.

기존 Render 정적 사이트를 갱신하며 새 서비스는 만들지 않는다.
