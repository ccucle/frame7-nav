# FORMDAY v0.8.1 — 운동 진행 바텀시트

사용자 요청에 따라 운동 시작/이어하기 화면을 아래에서 올라오는 큰 창으로 변경했다.

## 동작

- 운동 메뉴 위에 네이티브 모달 `dialog`를 열고 아래에서 위로 슬라이드한다. 배경은 어둡게 유지하고 둥근 상단 모서리와 손잡이를 표시한다.
- 창 안에서 종목 목록을 스크롤한다. 타이머와 지표는 위에, 종목 추가와 휴식 타이머는 아래에 고정한다.
- 손잡이/접기 버튼, 배경 누르기, Escape, 충분히 아래로 내리는 손잡이 제스처로 닫는다. 짧거나 옆으로 움직이는 제스처는 창을 닫지 않는다.
- 닫기 전에 현재 입력을 저장한다. 잘못된 값이나 저장 실패가 있으면 입력과 창을 유지하고 오류를 보여준다.
- 창을 닫는 동작은 운동을 종료하거나 일시정지하지 않는다. 같은 운동을 다시 열어 이어간다. 일시정지/임시 보관/완료는 기존 명시적 조작을 사용한다.
- 세트 갱신 때 창을 새로 열지 않으며 스크롤 위치와 펼친 상세 설정을 보존한다.
- 운동 창에서 종목 선택창을 열고 닫아도 운동 창을 유지한다. 선택창 닫기 후 포커스를 운동 창 안으로 복원한다.
- 닫기 애니메이션 중 반복 입력을 막고, 오래된 지연 콜백이 이후 화면을 덮어쓰지 않도록 한다.
- 화면 움직임 줄이기 설정에서는 애니메이션을 생략한다.

## 검증

- Node.js 24 전체 자동 테스트: **216개 통과, 실패 0개**.
- 신규 모달 검증 4개: 같은 dialog 유지·스크롤 보존, 잘못된 입력/저장 실패 시 닫기 차단, 중복 Escape 안전 처리, 손잡이 제스처 방향·거리·후속 클릭 처리.
- 기존 세트 저장/메모/이전 기록/타이머/앱 전환/동기화 보호 테스트 유지.
- JavaScript 문법 검사와 `git diff --check` 통과.
- 실제 iPhone 기기의 터치·키보드 동작 검증과 자동 테스트 결과를 구분한다.

저장 형식, Firebase 설정, 과거 기록은 변경하지 않는다. 기존 Render 정적 사이트에 배포한다.
