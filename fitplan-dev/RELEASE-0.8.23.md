# FORMDAY v0.8.23 — 프로그램 삭제 이중 확인

- 첫 삭제 클릭은 전용 네이티브 dialog만 표시하며 데이터 변경은 하지 않는다.
- 이름과 삭제 범위를 명시하고 취소에 초기 포커스를 둔다. 취소·Escape·배경 닫기·화면 이동으로 요청을 폐기한다.
- 별도의 최종 프로그램 삭제 버튼 및 확인 대상 ID, 화면, 버전, 프로그램 내용 일치 시에만 기존 저장 경로로 삭제한다.
- 확인 중 클라우드 적용을 보류하고 다른 탭의 저장 버전 충돌을 기존 검증으로 막는다. 오류나 확인창 지원 실패 시 원본을 유지한다.
- 루틴, 캘린더 일정, 운동 기록에는 변화 없음. 테스트 데이터 이외 사용자 프로그램을 직접 삭제하지 않음.
