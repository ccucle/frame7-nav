Google 계정과 데이터 연결 상태를 확인하는 중입니다.

첫 연결 방법

  1. 아이폰의 기존 기록을 JSON 백업합니다(캘린더와 IRON MODE 각각).
  2. 이 아이폰에서 이 기기 기록 최초 업로드를 실행합니다.
  3. 다른 기기에서 같은 Google 계정으로 로그인하고 클라우드 기록 불러오기를 선택합니다.
  4. 이후 정상 연결된 기기에서는 변경 사항이 자동으로 반영됩니다.

현재 Firestore 보안 규칙이 읽기·쓰기를 모두 막고 있으면 먼저 소유자 전용 규칙을 적용해야 합니다. Firebase Firestore 규칙 열기

다른 기기에 저장된 별도의 기록이 있다면 자동으로 합쳐지지 않습니다. 삭제 전 백업하세요. 동기화 오류가 나더라도 기존 로컬 기록은 유지합니다.

Cloud Firestore는 무료 사용량 한도가 있으며, 이를 초과하면 동기화가 일시 중단될 수 있습니다. 유료 요금제 전환은 하지 않습니다.
